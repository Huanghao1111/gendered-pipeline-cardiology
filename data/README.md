# Local data

No individual-level data or analysis results are distributed in this directory.

The scripts expect local frozen extracts, adjudication tables, and derived analysis files. Blank article-eligibility templates are provided in `config/`; the scripts document the required file names, fields, and environment variables.

Generated inputs, review logs, resumable files, and model outputs are written to `data/` or `work_tmp/` and excluded from version control. Manual labels, author-verification records, signed input tables, and authorization manifests remain local.
